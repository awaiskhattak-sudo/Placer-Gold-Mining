# Placer Gold Mining — AI Search Engine

A RAG (Retrieval-Augmented Generation) search engine over 3 knowledge-base
documents about a placer gold mining operation (Shakardara, Indus River):
operation workflow, equipment/fuel requirements, and finance.

**Architecture**: FastAPI + Jinja2 + HTMX for the UI, Gemini for embeddings,
ChromaDB for vector storage, and a local Ollama model (`llama3.2:1b`) for
answer generation and groundedness validation.

## 1. Setup

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate

pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add your real Gemini API key:
```
GEMINI_API_KEY=your_actual_gemini_api_key_here
```
Get a key at https://aistudio.google.com/apikey

Install and start Ollama, then pull the generation model:
```bash
ollama pull llama3.2:1b
```
(Ollama's service normally runs automatically after install; if not, run `ollama serve`.)

## 2. Build the knowledge base (run once, in this exact order)

```bash
python chunker.py                   # docs/*.txt -> chunks.json
python embed_chunks.py              # chunks.json -> embedded_chunks.json (calls Gemini)
python build_vector_store_chroma.py # embedded_chunks.json -> chroma_db/
```

Re-run these three only if you change the documents in `docs/`.

## 3. Run the app

```bash
uvicorn main:app --reload
```

Visit http://127.0.0.1:8000 — ask a question, get an answer with a
validity badge (✓ Valid / ✗ Not Grounded) and the source chunks used.

## 4. Tune the relevance threshold

`rag_pipeline.py` has `RELEVANCE_DISTANCE_THRESHOLD = 0.6` — this decides
when a question is "out of scope" for the knowledge base. Once the app is
running with real embeddings, test a few clearly relevant and clearly
unrelated questions, note the `distance` values shown under Sources, and
adjust this constant so it sits between the two clusters you observe.

```
│   ├── 05_requirement.txt
│   └── 06_finance.txt
├── chunker.py                         # Step 1: chunking (LangChain)

├── templates/

│   └── results.html                   # answer fragment
├── requirements.txt
├── .env.example
├── .gitignore
└── README.md

# Generated by running the pipeline (not committed to git):
├── chunks.json
├── embedded_chunks.json
└── chroma_db/
```
